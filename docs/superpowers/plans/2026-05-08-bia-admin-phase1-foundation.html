POST /api/admin/members/invite → withRole('super_admin') → insert admin_invitations → auth.admin.inviteUserByEmail() → audit_log: invite_sent
Invitee gets templated invite email → clicks link → GET /auth/callback?code=... → exchangeCodeForSession
